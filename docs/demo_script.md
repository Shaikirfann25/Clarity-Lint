# Person 5 Demo Script (4 minutes)

1. **Problem (30 sec):** Clarity Lint detects possible ambiguity in requirements, contracts, and policy text. It is a writing aid, not a legal decision-maker.
2. **Sentence analysis (45 sec):** Use “The admin monitors the user with the sensor.” Explain that the phrase may describe the admin's tool or a sensor associated with the user.
3. **Document summary (45 sec):** Paste several sentences, show sentence count, flagged count, ambiguity type breakdown, and explain that ambiguity rate is project-defined.
4. **Evaluation (60 sec):** Load real predictions for the same frozen test IDs. Explain macro-F1, per-class precision/recall/F1, and confusion matrix. State the environment used for latency measurement.
5. **Error analysis (40 sec):** Show a real false positive and false negative and what the team learned.
6. **Limitations (20 sec):** Small/synthetic data, heuristic false positives, possible missed ambiguity, uncalibrated model scores, and need for human review.

Never present synthetic fixtures as real results.
