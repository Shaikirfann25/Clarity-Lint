# Frontend feature inventory

## Application shell
- Editorial multi-page workspace shell based on the supplied Canonry experience.
- Imperial Jade / gold visual identity.
- Grouped navigation, compact sidebar, mobile drawer and keyboard command palette.
- Live clock, API indicator and persistent dark/light theme.
- Responsive layouts for desktop, tablet and mobile.

## Overview
- Product positioning and pipeline overview.
- Ambiguity-family and detection-path summary.
- Live health request to the FastAPI backend.
- Direct navigation into primary workflows.

## Analyze Text
- Sentence input with sample clauses and character counter.
- API-backed analysis with loading, success and error feedback.
- Finding cards show label, evidence span, source and reason.
- Separate tabs for findings, readings, rewrites and run details.
- Copy controls and explicit fallback-mode disclosure.

## Document Review
- Multi-sentence document input and word/character counts.
- API-backed sentence-level results.
- Expandable sentence rows, flag counts and explanations.
- Document summary, type distribution and JSON export.

## Evaluation Lab
- Loads the backend's demonstration evaluation.
- Uploads labelled CSV files for actual calculation.
- Displays accuracy, macro F1 and confusion matrices where returned.
- Explicitly distinguishes synthetic demonstration fixtures from measured results.

## Error Analysis
- Searchable and filterable curated examples.
- False-positive, false-negative and boundary-case categories.
- Clear disclosure that the examples are illustrative, not empirical rates.

## Integration Centre
- Live health and status requests.
- Endpoint inventory and operational guidance.
- Last-check timestamp, raw status response and retry control.

## Viva & Demo
- Expandable technical questions and answers.
- Timed presentation walkthrough.
- Architecture overview and honest limitation reminders.

## Settings
- Persistent theme selection.
- Compact navigation preference.
- Review and data integrity principles.
